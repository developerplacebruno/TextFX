# TextFX
Visual effects for text in Roblox

## Effects:

- **Counting**: Gradually changes the number in a text. Example from 1 to 5: 1, 2, 3, 4, 5. 

$$
Example of use: currency display and stopwatch...
$$

- **Typewriter**: Displays the text gradually, in the style of a typewriter. Example of use: notification, tutorial, and dialogue.
